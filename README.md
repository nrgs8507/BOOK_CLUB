\# 📚 Book Club — Electronic Book Club System



پروژه‌ی درس برنامه‌نویسی پیشرفته (C++/Qt) — معماری Client-Server با ارتباط از طریق TCP Socket و پروتکل JSON.



\## وضعیت فعلی پروژه



با توجه به محدودیت زمانی، این نسخه شامل یک مسیر کامل، تست‌شده و end-to-end برای بخش احراز هویت و جستجوی کتاب است. کلاس‌های منطقی خرید/کتابخانه نیز آماده و کامپایل‌شده‌اند، اما هنوز به سرور و رابط کاربری متصل نشده‌اند.



\### ✅ کامل، وصل‌شده و تست‌شده (end-to-end)

\- ثبت‌نام / ورود / فراموشی رمز عبور — از طریق سوکت واقعی (TCP)

\- جستجوی کتاب — جستجو بر اساس عنوان/نویسنده/ژانر و نمایش همه‌ی کتاب‌ها

\- نمایش کارت کتاب با جزئیات قابل باز/بسته‌شدن (قیمت، امتیاز)

\- ذخیره‌سازی اطلاعات کاربران و کتاب‌ها به‌صورت فایل JSON، با هش دوطرفه/یک‌طرفه طبق سند پروژه



\### 🟡 آماده ولی وصل‌نشده (کد کامل و کامپایل‌شده، بدون

اتصال سرور)

کلاس‌های زیر پیاده‌سازی و در پروژه ادغام شده‌اند، اما به دلیل کمبود زمان هیچ‌کدام از طریق سرور یا رابط کاربری قابل استفاده نیستند:

\- Cart / CartManager — افزودن/حذف کتاب از سبد، محاسبه‌ی مجموع قیمت، و منطق کامل checkout (ثبت تراکنش + انتقال به کتابخانه‌ی شخصی + افزایش شمار فروش)

\- Library / LibraryManager / Shelf — کتابخانه‌ی شخصی و قفسه‌بندی

\- Transaction / TransactionManager — ثبت تراکنش‌های خرید

\- Discount (انتزاعی) + PercentDiscount / TimedDiscount — تخفیف درصدی و زمان‌دار



\### ❌ پیاده‌سازی‌نشده (به دلیل کمبود زمان)

\- پنل ناشر و پنل مدیر سیستم

\- سیستم اعلان‌ها (Notification System)

\- رابط گرافیکی برای سرور (فعلاً سرور فقط از طریق کنسول قابل مشاهده‌ست)

\- ماژول مطالعه‌ی PDF

\- Installer نهایی

\- بخش‌های امتیازی (پایگاه‌داده SQL، Multi-threading، نمودار آماری، مطالعه‌ی گروهی، QML)



\## معماری



\- BOOK\_CLUB — کلاینت (رابط گرافیکی Qt Widgets)

\- BOOK\_CLUB\_SERVER — سرور (بدون رابط گرافیکی، اجرا در کنسول)

\- ارتباط از طریق QTcpServer/QTcpSocket، با پروتکل پیام‌های JSON جداشده با کاراکتر \\n

\- هر پیام شامل فیلد action (مثل login, register, searchBooks, getAllBooks) و فیلد status (ok یا error) در پاسخ



\## نحوه‌ی اجرا



1\. ابتدا BOOK\_CLUB\_SERVER.exe را (مستقل، خارج از IDE) اجرا کنید. باید پیام

&#x20;  Server is listening on port 5050 نمایش داده شود.

2. سپس BOOK\_CLUB.exe (کلاینت) را اجرا کنید.

3. یک کاربر جدید ثبت‌نام کنید یا با کاربر موجود وارد شوید.

4. پس از ورود موفق، صفحه‌ی جستجوی کتاب به‌طور خودکار باز می‌شود (به‌جای داشبورد کامل که هنوز طراحی نشده).

5. با دکمه‌ی Show All یا جستجو بر اساس عنوان/نویسنده/ژانر، لیست کتاب‌ها نمایش داده می‌شود.



> نکته: در صورت اجرای هر دو برنامه از طریق Qt Creator به‌صورت هم‌زمان، ممکن است IDE

> فرآیند قبلی را متوقف کند. توصیه می‌شود سرور را مستقل از IDE اجرا کنید.
